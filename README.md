# Distributed Chat Application

A Python-based distributed chat application developed for the Distributed Computing Systems assignment.

## Project Objectives

- Enable real-time communication between multiple clients.
- Use TCP sockets for network communication.
- Support multiple server nodes.
- Broadcast messages between clients connected to different servers.
- Implement basic fault tolerance through server failover.

## Planned Technologies

- Python
- TCP sockets
- Threading
- Git and GitHub

## Project Structure

- `client/` — Chat client implementation.
- `server/` — Server nodes and connection handling.
- `common/` — Shared communication protocol and utilities.
- `tests/` — Application tests.
- `screenshots/` — Demonstration screenshots.
- `logs/` — Optional message logs.

## Project Status

Initial project setup. Implementation will be added incrementally and documented through meaningful Git commits.
